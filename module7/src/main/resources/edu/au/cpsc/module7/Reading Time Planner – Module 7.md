Vision:

This application helps users estimate the total reading time for a book and provides a monthly reading calendar based on how fast the user reads the pages of their book and how long they spend reading it uninterrupted.

Features:
User will put into the first line of the interface how many pages they are trying to read
Next, they will input how fast they can finish a page in minutes 
The user can choose to include breaks if they are plannig to read for a long period of time
Once all that information is collected, the program will estimate how long it will take you to read

The user can then click tools and click on Monthly Plan

The user will select the day they want to start reading, when they want to be done by, and how many days out of the week they want to commit to reading

System will print out a schedule you can stick to in order to finish reading on time.
